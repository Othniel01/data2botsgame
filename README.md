# 🎮 Dino Runner Clone (Custom Edition)

A **Chrome Dino Game clone** built with **Next Js + TypeScript + HTML5 Canvas**, featuring **hand-drawn sprites** created by me in **Piskel**.  

This project was built as part of my application to **Data2Bots Academy** I wanted to go beyond a simple coding task and create something **fun, technical, and creative**.

---

## 🚀 About the Project
The Chrome Dino Game is a nostalgic classic. I decided to rebuild it from scratch to showcase:
- My ability to **design, structure, and implement game logic** using React + Canvas  
- My creativity in **drawing all the sprites by hand**  
- My drive to **show initiative beyond standard coding exercises**

The result: a fully functional mini-game that is both technically solid and visually unique.  

---

## 🎯 Thought Process & Motivation
When applying to Data2Bots Academy, I asked myself:  

> *“How can I prove I can think like both a developer and a creator?”*  

- I chose a **familiar game** so recruiters and developers could play instantly without explanation.  
- I coded it entirely in **TypeScript** to demonstrate type safety and clean architecture.  
- I used **Canvas** for efficient rendering and real-time updates.  
- I drew my own **sprites in Piskel**, because I believe polish and design matter as much as functionality.  

---

## ⚡ Features
- Smooth **game loop** powered by `requestAnimationFrame`  
- **Jump & duck mechanics** with gravity simulation  
- **Procedural obstacle generation** for replayability  
- **Score tracking** with increasing difficulty  
- **Custom sprites** (character, obstacles, background) all drawn by me  
- Type-safe and structured with **Next js + TypeScript**  

---

## 🛠️ Tech Stack
- **Next Js** – UI & component structure  
- **TypeScript** – Type safety & maintainability  
- **HTML5 Canvas API** – Real-time rendering & physics  
- **Piskel** – Pixel art sprite design  

---

## 🎨 Custom Sprite Design
All visuals (dino, obstacles, ground, background) were designed and hand-drawn by me in **Piskel**.  
This gave the game a **unique look** and allowed me to practice **pixel art + UI/UX thinking**.
